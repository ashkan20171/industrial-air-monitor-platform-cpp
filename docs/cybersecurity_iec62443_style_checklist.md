# IEC 62443-Style Cybersecurity Checklist

This is not a certification document. It is a professional engineering checklist inspired by industrial cybersecurity practices.

## Identity and Access
- [ ] Unique user accounts
- [ ] Role-Based Access Control
- [ ] Password policy
- [ ] Session timeout
- [ ] Least privilege

## Network Security
- [ ] Separate OT and IT networks
- [ ] Firewall rules defined
- [ ] Only required ports open
- [ ] OPC-UA/MQTT TLS plan
- [ ] VPN/secure remote access policy

## System Hardening
- [ ] Disable unused services
- [ ] Secure default configuration
- [ ] Signed installer/update plan
- [ ] Logging enabled
- [ ] Backup/restore procedure

## Monitoring and Audit
- [ ] Login attempts logged
- [ ] Alarm acknowledgement logged
- [ ] Configuration changes logged
- [ ] Data export logged
- [ ] Time synchronization configured

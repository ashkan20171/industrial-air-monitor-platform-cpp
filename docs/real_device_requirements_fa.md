# اطلاعات لازم برای اتصال واقعی

برای اتصال واقعی به Ecotech، BAM، Horiba، ESA یا هر دستگاه دیگر، لطفاً برای هر مدل این اطلاعات را بده:

1. نام دقیق مدل
2. نوع ارتباط: RS232 / RS485 / LAN / USB
3. تنظیمات پورت: baud, parity, data bits, stop bits
4. دستور درخواست داده یا register map
5. نمونه پاسخ خام دستگاه
6. لیست پارامترهای مورد نیاز مثل PM2.5, PM10, NOx, SO2, O3
7. اگر CRC یا checksum اختصاصی دارد، نمونه آن
